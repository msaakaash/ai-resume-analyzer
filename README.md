<h1 align="center">AI Resume Analyzer</h1>

## Overview
An AI-powered resume analysis system that uses Retrieval-Augmented Generation (RAG) to parse resumes, evaluate job fit, generate interview questions, and provide intelligent insights using a fully local LLM setup.

## Tech Stack
Python  
LangChain  
Streamlit  
ChromaDB  
HuggingFace  
Ollama  
LLM (Llama 3)
